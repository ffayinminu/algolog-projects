# Spacer — Value Stack

**Purpose:** Itemised breakdown of what a client actually receives when they pay for a Spacer deployment. Used in closes to anchor price against value delivered.

**Investment Anchor:** ₦3,000,000 (hospitality) / ₦2,000,000 (apartments) — one-off.

---

## What Clients Receive

### 1. Multi-Tenant Platform Core
A production-grade, multi-tenant SaaS infrastructure already serving live properties across Lagos, Abuja, Kaduna and Bwari. Custom branding, dedicated URL, role-based access, JWT authentication, audit logging, and real-time WebSocket infrastructure — out of the box.

- Multi-tenant architecture with isolated data per property
- Custom subdomain / branded URL per client
- JWT + Passport authentication, bcrypt hashing
- Role-based access control (Owner, Manager, Receptionist, Cashier)
- Audit logging for every state change
- Real-time updates via WebSocket

**Build-it-yourself equivalent: ₦8,000,000**

---

### 2. Multi-Tier Booking Engine
The booking layer that powers every Spacer deployment — handling hourly, daily, weekly, monthly, quarterly, bi-annual, and annual reservations under one engine, with conflict prevention, virtual subspaces (coming), and admin override controls.

- Hourly, daily, weekly, monthly, quarterly, bi-annual, annual tiers
- Automatic conflict prevention with admin override toggle
- Virtual spaces / subspace packages (1BR/2BR under 3BR parent)
- Calendar integration (Google Calendar, internal calendar views)
- Cart abandonment recovery flow

**Build-it-yourself equivalent: ₦7,000,000**

---

### 3. Payment Infrastructure
Full Paystack integration that eliminates manual reconciliation, recovers no-shows via payment-first logic, and replaces the WhatsApp-and-Excel workflow entirely.

- Paystack card + bank transfer (1.5% capped at ₦2,000)
- Automated invoice generation
- Automated receipt generation and delivery
- Subscription and renewal automation (cron-driven)
- Refund handling
- Arbitrary/manual invoice creation for ad-hoc charges
- Cart abandonment tracking and recovery emails

**Build-it-yourself equivalent: ₦6,000,000**

### 4. Smart Lock Automation

- Tuya cloud-synced online code generation

- QR-based building entrance access
- QR check-in validation against active bookings
- Multi-account device handling

**Build-it-yourself equivalent: ₦5,000,000**
